# Code of Conduct

WinGet Studio adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. It applies in every project space: issues, pull requests, reviews and commit messages.

In short: be respectful, assume good faith, criticise the code and not the person, and accept that the maintainer has the last word on what gets merged.

## Reporting

Report unacceptable behaviour to **fborghi1996@live.it**. Reports are read only by the maintainer and kept confidential. The enforcement guidelines are those of the Contributor Covenant linked above.
